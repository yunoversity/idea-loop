# idea-loop

A self-improving business-idea brainstorming pipeline, run by a Chief of Staff
agent in Claude Code. See [CLAUDE.md](CLAUDE.md) for the operating manual and the
[requirements spec](https://claude.ai/code/artifact/fb275a50-8de2-4482-a31e-71c66eaefee6)
for the full design.

Quick start (in a Claude Code session in this repo):

- `/capture <brain dump>` — file a painpoint
- `/brainstorm <id>` — think it through with open-ended questions
- `/meeting` — convene the staff meeting
- `/graduate <id>` / `/park <id>` — your decisions, executed with full bookkeeping
