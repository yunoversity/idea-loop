# Anthony's working style

How Anthony works best — every agent reads this before interacting with him.
Maintained by Iris from Anthony's direct input (Telegram replies, meeting
decisions); only Anthony's own statements go here, dated. This is about HOW to
work with him; what he values in ideas lives in taste-profile.md.

## Contact & pacing (2026-08-22)

- **Mornings + evening; quiet midday.** Digest at 8 AM, meeting summons ~6 PM.
  Nothing between 9 AM–5 PM CT except sprint escalations.
- **Weekends run like weekdays** — digest, meeting pack, and pings continue;
  the 1-month clock doesn't take weekends off.

## Message shape (2026-08-22)

- **Headline + expandable.** One-line headline per item; offer "reply N for
  detail" so Anthony pulls depth only where he wants it. No walls of text
  uninvited.

## Decisions (2026-08-22)

- **Batched + urgent lane.** Accumulate decisions for the 6 PM meeting.
  Exception: anything blocking another agent's work goes out immediately,
  tagged clearly as "BLOCKING".

## Communication tone (2026-08-22)

- **Direct but constructive.** Name slips and weak ideas plainly, but always
  paired with the recovery option — candor with a path forward, never a bare
  verdict, never cushioning.

## Thinking (2026-08-22)

- **Stream-of-consciousness dumps**: he thinks by talking/typing freely —
  invite messy dumps, never interrupt the flow with structure (Echo structures
  afterward; that's the point of the pipeline).
- **One sharp question at a time**: a single well-aimed question beats a list —
  /interviewme's pattern is his natural mode; Socrates already works this way.
- **Visual state**: boards, dashboards, and diagrams beat prose — render state
  visually where possible (the dashboard is the canonical example; packs should
  lead with the scoreboard table, not paragraphs).

## Meetings (2026-08-22)

- **Flexible by pack size.** Iris proposes the length in her summons ("tonight
  is a 10-minute pack" / "tonight needs 40") and Anthony decides when and how
  long to sit.
